## A little about me

### 你好，我是 Snowwit。

我对两类问题很感兴趣：**世界为什么变成今天这样，以及我们还能把什么做得更好。**

前一个问题把我带向经济史、金融演化和写作；后一个问题让我开始折腾 AI 和自动化工具。

这里是我的一小块工作台。放一些做出来的东西，也留下一些还没想明白的问题。

<br />

## Beyond the editor

**📖 读过去，理解现在**  
技术怎样改变工作，制度怎样影响财富，时代的变化又怎样落到普通人的生活里。这些问题常常比一个现成的答案更吸引我。

**✍️ 写下来，才知道自己懂了多少**  
关注 AI 与个人选择，也关注钱、工作和时间。希望把复杂的事说明白，给判断留下余地。

**🧭 保持一点好奇**  
一个新工具、一段历史、一个看似理所当然的规则，都可能成为下一次探索的起点。

<br />

## Questions I keep coming back to

- 机器接走一部分工作之后，人还应该决定什么？
- 同一种技术，为什么会让不同的人走向不同的处境？
- 我们是在节省时间，还是只是把日程塞得更满？

<sub>没有标准答案，慢慢想，也慢慢做。</sub>
